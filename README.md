## ScriptList

- **auto_light_camera_setup**  
Comprehensive Blender 4.x add-on for automatic lighting, camera positioning, multi-shot generation, and batch processing. Features include:
    ・Automatic three-point lighting setup  
    ・Camera positioning with multiple shot types (front, 3/4, top, low)  
    ・Preset system (Product, Character, Small Prop, Flat Art, Architectural)  
    ・Batch collection processing  
    ・HDRI environment support  
    ・Headless CLI automation for CI/CD pipelines  
    ・Professional rendering workflows

- combine  
選択中のコレクション配下のオブジェクトに対して、下記の処理を順次実行します。  
    ・カーブをメッシュ化  
    ・モデファイアを適用  
    ・オブジェクトを結合  


- vertexcolor  
すべてのコレクション内のメッシュオブジェクトのマテリアルにVertexColorの参照を追加します。
